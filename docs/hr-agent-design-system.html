Colour tokens
All colours are defined as CSS custom properties in tokens.css. Never use raw hex values in components — always reference a token. This ensures dark mode works automatically.
🚧 Never hardcode #534AB7 in a component. Write var(--brand-600) or the Tailwind class bg-brand-600 instead.

Typography
Two weights only: 400 (normal) and 500 (medium). Never use 600 or 700 — they read too heavy against the app chrome. Font stack: Inter → system-ui → Arial.

Do / don't
✓ Do
font-weight: 500 for labels and headings

font-size: var(--text-sm) for body content
✗ Don't
font-weight: 600 or 700 — too heavy

Raw px values like font-size: 12px — use tokens
Spacing & radius
Spacing follows Tailwind's 4px base unit. Use the standard scale — no custom values. Border radius uses named tokens: sm (4px) for compact controls, md (8px) for most elements, lg (12px) for cards, full for pills and avatars.

Do / don't
✓ Do
One btn-primary per screen. Use btn-secondary for Cancel. Use btn-ghost for "Ask agent" links.
✗ Don't
Multiple primary buttons in one view. Raw <button style="background:#534AB7">. Font weight above 500.

Dark mode
Dark mode is automatic — it follows the OS preference via @media (prefers-color-scheme: dark) in tokens.css. You never need to add dark: Tailwind variants to components — just use token variables and it works.

Do / don't

✗ Don't
